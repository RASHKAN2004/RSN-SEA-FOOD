# Product Images

Place your own product photography here, using these exact filenames so they match
`frontend/data/products.js` and the backend seed data:

```
/images/products/
  anchovy.jpg
  barramundi.jpg
  crab.jpg
  tuna.jpg
  skipjack-tuna.jpg
  mackerel.jpg
  sailfish.jpg
  seer-fish.jpg
  sardine.jpg
  prawn.jpg
  cuttlefish.jpg
  squid.jpg
  lobster.jpg
  mullet.jpg
```

Recommended: square or 4:3 images, at least 800x800px, consistent lighting and crop
so every product card looks uniform. Until real photos are added, you can point
`image` fields in `data/products.js` to temporary stock photo URLs (e.g. Unsplash)
the same way the homepage hero image is set up in `app/page.js`.
